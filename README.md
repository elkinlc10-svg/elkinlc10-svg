# Hola, soy Elkin 👋

Desarrollador **full-stack y móvil** de Colombia. Hago productos que se usan de verdad:
una tienda en línea en producción, una app bíblica en Flutter, un sistema de kiosco
para un negocio de alquiler de juegos y una landing que vende con pagos en línea.

- 🛠️ **Móvil:** Flutter · Dart · Firebase (Auth, Firestore, Cloud Functions)
- 🌐 **Web:** JavaScript · Node.js · HTML/CSS · Vercel (funciones serverless)
- 🖥️ **Escritorio:** Electron · Three.js
- 🐍 **Python:** Flask · automatización
- 💳 **Integraciones:** pagos con Wompi, AdMob, compras dentro de la app, notificaciones

## ⭐ Proyectos destacados

### 🛍️ Boom Detalles — tienda en línea (en producción)
Tienda de detalles y regalos con catálogo y pedidos, publicada en Vercel.
**[Ver la tienda en vivo →](https://boom-detalles-tienda.vercel.app)**
Código privado (negocio real)

### 📖 Lumina — app bíblica para jóvenes
App Flutter con inicio de sesión (Google y correo), progreso por niveles y mundos, quizzes en
español e inglés, lectura en voz alta, notificaciones diarias, widget de pantalla de inicio,
anuncios y compras dentro de la app.
`Flutter` `Firebase Auth` `Firestore` `Cloud Functions` `AdMob` `Compras in-app`
Código privado

### 🎮 Zona Gamer — kiosco de alquiler de juegos
Aplicación de escritorio en modo kiosco para un local de alquiler de PC por tiempo: los jugadores
piden turno desde su control, el encargado cobra con PIN y el sistema activa cada control,
lleva ventas, perfiles y ranking. Se reinicia sola si se cae.
`Electron` `Three.js` `Node.js` `Python`
Código privado (negocio real)

### 💸 Sin Rodeos — landing con pagos en línea
Landing que vende una guía en PDF: pago con Wompi, verificación de la transacción en el
servidor y descarga con enlace firmado (HMAC) para que el archivo no quede público.
`JavaScript` `Vercel Functions` `Wompi` `HMAC`
Código privado

### 🕹️ TicTacon — colección de minijuegos
App Flutter con varios minijuegos, manejo de estado con Provider, sonidos y guardado local.
`Flutter` `Provider` `SharedPreferences`

### 🙌 100 Cristianos Dicen — juego de concurso
Juego estilo concurso para eventos: una pantalla para el presentador y otra para el público,
sincronizadas en el navegador, con preguntas cargadas desde JSON y efectos de sonido.
`JavaScript` `HTML/CSS`

### 🎬 YoutubeMP4 — conversor de video local
Aplicación web local en Flask que baja videos en 1080p, 720p o 480p, permite recortar y quitar
el audio. Descarga por partes en paralelo con caché y un puente HTTP local para ffmpeg.
`Python` `Flask` `yt-dlp` `ffmpeg` `Concurrencia`
